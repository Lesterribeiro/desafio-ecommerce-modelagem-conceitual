Refinando um Projeto Conceitual de Banco de Dados – E-commerce
Descrição
Projeto desenvolvido como desafio da Formação SQL Database Specialist.

O objetivo consiste em refinar um modelo conceitual de E-commerce adicionando novas regras de negócio relacionadas a clientes, pagamentos e entregas.

Melhorias Implementadas
Cliente PF e PJ
Uma conta pode ser Pessoa Física ou Pessoa Jurídica, mas não ambas simultaneamente.

Pagamentos
Um cliente pode possuir múltiplas formas de pagamento cadastradas.

Entrega
Cada entrega possui status e código de rastreio para acompanhamento.

Melhorias Extras
Cadastro de múltiplos endereços.
Categorias de produtos.
Histórico de status dos pedidos.
Regras de Negócio
Um cliente pode realizar vários pedidos.
Um cliente pode possuir vários endereços.
Um cliente pode possuir várias formas de pagamento.
Um pedido pode conter vários produtos.
Um produto pode participar de vários pedidos.
Cada pedido possui uma entrega.
Cada pedido possui histórico de alterações de status.
Modelo Conceitual
A imagem do modelo conceitual encontra-se na pasta docs.
